# Repository principles

These rules apply to **every** project in this account, without exception.

## 1. Original work only
- Every project starts from scratch, with its own purpose and a neutral theme.
- No code, data, spreadsheets, dashboards or text brought in from employers, clients or courses.

## 2. Real data never enters
- Only **fictitious** data, generated by script, stored in `examples/`.
- Forbidden: real names, national ID numbers, emails, phone numbers, addresses, account numbers.

## 3. Personal context stays out
- Commit messages, pull requests and comments describe **the code**, never personal or professional context.

## 4. Private by default
- Every repository is created **private**.
- A repository becomes public only after a full review (see `SECURITY-CHECKLIST.md`, part C).

## 5. Automatic barrier
- The hook in `.githooks/pre-commit` blocks commits that contain forbidden files or content.
- Enable once per clone: `git config core.hooksPath .githooks`
